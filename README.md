# Abdul Wahab - Personal Portfolio

A responsive personal portfolio website for introducing Abdul Wahab, highlighting his skills and projects, and providing ways to get in touch. The site is built with plain HTML and CSS and does not require a JavaScript framework or build tools.

## Website sections

- **Home:** Short introduction, portrait, and links to projects and LinkedIn.
- **About:** Background and highlights focused on web design and responsive layouts.
- **Skills:** HTML, CSS, responsive web design, JavaScript fundamentals, and Canva/graphic design.
- **Projects:** A visual gallery of portfolio, football club, wedding invitation, and education website concepts.
- **Contact:** Email and phone links, location, and a contact form that opens an email client.

## Built with

- Semantic HTML5
- CSS3, including Grid, Flexbox, transitions, and responsive media queries
- Local images stored in the `image/` folder

## Run locally

No installation or build step is needed:

1. Clone or download this repository.
2. Open `index.html` in a web browser.

For a local development server, open the project folder in Visual Studio Code and use an available static-server extension.

## Project structure

```text
personal-portfolio/
├── image/       # Portrait and project preview images
├── index.html   # Portfolio content and page structure
├── style.css    # Layout, visual styles, and responsive rules
└── README.md    # Project documentation
```

## Customization

- Edit the text, navigation, project cards, and contact links in `index.html`.
- Update colors, spacing, layouts, and breakpoints in `style.css`.
- Replace or add images in `image/`, then update the corresponding image paths in `index.html`.

The contact form uses a `mailto:` action, so submitting it depends on an email application being configured in the visitor's browser or device.
